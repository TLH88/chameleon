# Chameleon for Kodi

Chameleon is a Kodi 21 (Omega) skin with switchable looks, plus a small helper add-on that sets everything up for you.

## Install

1. In Kodi, open Settings, System, Add-ons and turn on **Unknown sources**.
2. Download `script.chameleon.helper-0.2.8.zip` from this repository.
3. In Kodi, open Add-ons, **Install from zip file**, and pick that zip.
4. A setup wizard starts on its own. It installs the skin and the add-ons it needs, signs you in to Trakt and Premiumize, configures playback, and lets you pick a look.

The wizard can be reopened any time from Add-ons, Chameleon Helper, Run setup wizard.

## What is in here

- `repo/` is a Kodi add-on repository. The wizard installs it so the skin and helper update themselves.
- `script.chameleon.helper-0.2.8.zip` is the one file you install by hand.

No accounts, keys or personal settings are included. Everyone signs in with their own.
